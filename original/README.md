# Locally supplied target

Place your legally obtained *Companions of Xanth* budget-CD files here after
extraction:

- `XANTH.EXE` — ISO member `XANTH/XANTH.EXE`
- `XANTH.OVL` — ISO member `XANTH/XANTH.OVL`

An executable named `XANTH.EXE` is not proof of this SKU. `tools/verify.py`
checks size and SHA-256 against `config/target.json`.

All files in this directory except this README and `.gitignore` are ignored.
Never force-add game binaries, overlays, assets, or proprietary toolchains.
No game download is provided by this repository.
