# Companions of Xanth native-port prerelease

## How to play

1. Download the attached Linux x86_64 asset named
   `xanth-r<N>-<commit>-linux-x86_64.tar.gz` and extract it to
   `~/Games/companions-of-xanth/port/`.
2. Supply **your own** `XANTH.EXE` plus the 90 runtime files in
   `DATA_FILES.txt`, copied from your original disc or an installation you
   already own. Put all 91 directly in
   `~/Games/companions-of-xanth/data/`. GOG currently has a Dreamlist page,
   not a store listing:
   [GOG Dreamlist](https://www.gog.com/dreamlist/game/companions-of-xanth).
3. Double-click `launch.sh` or run
   `~/Games/companions-of-xanth/port/launch.sh`.

No game data is included. Startup checks SHA-256 pins for every required
file. If it cannot find a valid directory, Linux opens a folder chooser; it
remembers a successful selection on this computer. A hash mismatch means the
set is incomplete or from a different release; this build supports the pinned
XANBUD set only. If no chooser is available, install `kdialog` on KDE or
`zenity` on GNOME, or pass the directory as `./launch.sh /path/to/game-data`.

### Steam Deck / Game Mode

In Desktop Mode, add `launch.sh` as a non-Steam game. Set **Start In** to the
package folder and Launch Options to `/home/deck/Games/companions-of-xanth/data`.
Add `--controller` to Launch Options to opt in to SDL gamepad controls, then
launch from Game Mode. This is a native Linux program; leave Force Compatibility
Tool disabled.

### Controls and optional settings

Mouse and keyboard are the defaults. With `--controller`, left stick moves
the pointer, A clicks, X right-clicks, D-pad sends arrows, and Start sends
Enter. Optional flags include `--pixel-perfect`, `--fit`, `--crt`, `--linear`,
`--fullscreen`, `--handheld`, `--hotkeys`, `--soundfont <your.sf2>`,
`--volume-{master,music,sfx,voice} N`, and `--mods <directory>` with
`--replacement-fonts` or `--replacement-graphics`. All enhancements are off
by default. See `docs/ENHANCEMENTS.md`.

## Release contents

Linux x86_64 port binary, SDL2 runtime with its license, launch script, and
documentation only. No game files, saves, mods, replacement assets, or
soundfonts are attached. The package requires glibc 2.34 or newer plus the
system's normal display and audio dependencies.

## Status and limitations

The port runs the retail game through its own 16-bit CPU/DOS VM and SDL2 HAL;
most guest instructions remain interpreted. The tested route reaches Fairy
Nuff's recipe and reads 122/1000 points. The full game is not completable yet.
Full-route DOSBox comparison for graphics, sound, timing, and gameplay has not
been established. Windows build/runtime support remains unverified. See
`docs/KNOWN_DIVERGENCES.md` for evidence and open work.
