# Companions of Xanth v0.1.0-alpha.2

Linux input fix for alpha.1: hide the host cursor over the game, correctly map mouse/button coordinates through letterboxing and high-DPI scaling, and retain quick mouse/touch/controller presses until the retail mouse poll observes them. The game still draws and processes its own cursor.

Controllers are detected automatically and support hotplug, analog pointer movement, A left-click, X right-click, D-pad guest arrows, Start Enter, and Back help. Steam/InputPlumber handheld filters include Legion Go 2 and background controller events. Use `--no-controller` to disable controller input.

Includes host event-filter, controller-mask and presentation-overlay hooks for the separately developed, opt-in dev menu. This release does not contain the dev menu or HD graphics. Source-backed hotspot snapping and contextual verb cycling remain pending verification.

Requires your own matching XANBUD game files; no game data is included. Saves and game behavior remain under the retail DOS executable. This is an experimental VM-assisted native port, not a completed native rewrite.
