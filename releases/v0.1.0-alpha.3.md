# Companions of Xanth v0.1.0-alpha.3

Fixes the black startup screen in alpha.1 and alpha.2. BIOS keyboard status
calls now return with interrupts enabled, as the BIOS does, so the game's
own timer advances and its logo fade runs in the real-time executable.

Mouse clicks retain every press and release until the guest polls its state;
window, fullscreen, letterbox and DPI transforms use the correct coordinates.
The system cursor is hidden over the game window. Controller input auto-enables
with a pad, includes the Steam/InputPlumber and Legion Go 2 sanitiser, pointer
acceleration, A/X clicks, and the authored help overlay. Y snaps within the
hovered live hotspot; LB/RB cycle the game's actual verb rows. Those helpers
read the live guest tables only after verified field idle and discard gestures
during dialogs or commands. They never write guest state.

Validation:
- Packaged real-time startup: 700 frames, 12,460 lit pixels, 8,326 timer ticks.
- Packaged ordinary X11 keyboard/mouse test, on private Xvfb: title to bedroom,
  then envelope taken; exact prior inventory and static-scene screenshot hashes.
  All four press/release states were observed in order by INT 33h.
- Production SDL virtual-pad snap and verb cycling, disabled input parity,
  cursor geometry/DPI, and BIOS interrupt-flag tests pass.
- The read-only observer preserves an identical VM report with 554,000,000
  instructions and 349,850 ticks. Modal pages never report field idle.
- Clock-corrected screenshot goldens were audited against prior builds:
  changed pixels occur only inside the verified animated rain rectangle.
- Strict retail-byte guard: zero failing runs in tracked source, executable,
  Linux package and source archive. Retail signature checks use one-way digests
  against the user's own executable. No retail data is bundled.

Your own matching game data is required. Linux uses system SDL2 and glibc 2.34
or newer. Physical-controller checks remain pending; the pad tests use SDL
virtual controllers. The opt-in dev menu and HD layer follow separately;
the event-filter, pad-mask and presentation-overlay hooks are included here.
