# Companions of Xanth v0.1.0-alpha.4

Dev menu is ON in this preview: press F12 or Back+Start. Set dev_menu=0 to hide it.
The menu has 8 verified warps and 7 finish-step entries after local setup.
You can also use --no-dev-menu to hide it; XANTH_CHEATS=0 hard-disables it.

Checkpoint entries require local building and verification with the included
Python tools and your own game data. No game files, saves, artwork or fonts
are supplied. The menu uses the game's own Restore dialog, reads only verified
idle state, checks checkpoint digests, and captures player input during the
restore. Its temporary save slots never replace existing player saves and
are removed after use or shutdown. The first save after a warp shows a
warning and records a line in xanth-dev-menu.log.

The menu is fully navigable with a keyboard or controller. Options include
fast-forward, screenshot, fullscreen and scanlines. F1-F10 and Backspace stay
with the game when the menu is closed. XANTH_CHEATS=0 hard-disables the menu.
No cheats or quick save/load are offered. Current checkpoints cover the
Mundania opening and first Xanth cavern; more areas need verified routes.

This includes the alpha.3 boot, cursor, mouse and controller fixes. Walkthrough,
Stage2 and font-test goldens were updated only after independent old/new pixel
audits showed every changed pixel inside verified rain/torch animation bounds.
The thunder-event save countdown differs because animation advances the shared
random sequence; no puzzle, score, inventory or story change was observed.

Linux x86_64 requires system SDL2 and glibc 2.34 or newer. The full game is
not yet completable; see the README for current route coverage.
